Aplicaciones Extras / Manchas

Configuración de mezclas especiales, focos y generación automática de órdenes y salidas
¿Qué es un Box? Cada Box representa una receta o mezcla química independiente aplicada a un grupo de bloques (ej. Box 1 para la mezcla de Hypericum y Box 2 para la mezcla de Solidago). Puedes añadir tantos boxes como focos o mezclas necesites. Al guardar, el sistema genera automáticamente el programa oficial, la hoja de aplicación imprimible y las salidas de bodega para pesaje y despacho.
